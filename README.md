# Waldo Chat

구글 계정(Gmail)으로 로그인해서 쓰는 팀 채팅 웹사이트야. Google Chat의 기본 기능을 따라 만들었어.

## 기능

**로그인과 사람**
- Google 계정 로그인(OAuth 2.0 / OpenID Connect). 들어올 수 있는 메일 도메인을 제한할 수 있어.
- 접속 상태(활동 중 / 자리 비움 / 방해 금지 / 오프라인)와 상태 메시지
- 아직 가입 안 한 사람도 Gmail 주소로 초대할 수 있어. 그 사람이 나중에 로그인하면 대화가 그대로 이어져.

**대화**
- 1:1 채팅, 그룹 채팅(여러 명)
- 스페이스: 이름, 아이콘, 설명, 공개/비공개, 관리자/멤버 역할, 멤버 추가·내보내기, 설정 변경, 삭제
- 공개 스페이스 찾아보기와 참여
- 대화 고정, 알림 끄기, 숨기기(새 메시지가 오면 다시 보여)

**메시지**
- 실시간 전송, 입력 중 표시, 읽음 표시(1:1·그룹), 안 읽은 수 배지
- 스레드 답장(오른쪽 패널), 답글 수와 참여자 표시
- 이모티콘 반응, 수정(빈 입력창에서 ↑ 키로 마지막 메시지 수정), 삭제(스페이스 관리자는 남의 메시지도 삭제)
- @멘션 자동 완성과 @all, 나를 멘션한 메시지는 강조
- 서식: `*굵게*` `_기울임_` `~취소선~` `` `코드` `` ```` ```코드 블록``` ````, 링크 자동 연결
- 파일·이미지 첨부(25MB까지, 끌어다 놓기·붙여넣기 지원), 이미지는 미리보기
- 별표표시한 메시지 모아 보기, 멘션 모아 보기
- 전체 검색과 대화 안 검색
- 데스크톱 알림(알림 끈 대화는 멘션만 알림, 방해 금지일 때는 알림 없음)
- 홈: 최근 대화와 읽지 않은 대화 모아 보기

**화면**
- 왼쪽 목록 / 가운데 대화 / 오른쪽 스레드, 다크 모드, 휴대폰 화면

## 실행

Node.js 22.13 이상이 필요해(내장 SQLite를 써).

```bash
npm install
cp .env.example .env   # 값 채우기
npm start              # http://localhost:3000
npm test
```

구글 키를 아직 안 넣었으면 로그인 화면에 **개발용 로그인**(이메일 + 이름)이 나와서 바로 써 볼 수 있어. 브라우저 창 두 개(하나는 시크릿 창)로 서로 다른 사람으로 들어가 보면 돼.

## 구글 로그인 설정

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들어.
2. **API 및 서비스 → OAuth 동의 화면**: 사용자 유형 "외부", 앱 이름과 지원 이메일을 넣어. 범위는 `openid`, `email`, `profile`이면 충분해. 테스트 단계에서는 "테스트 사용자"에 쓸 Gmail을 추가해 둬.
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**, 유형은 "웹 애플리케이션".
   - 승인된 리디렉션 URI: `BASE_URL/auth/google/callback` (예: `http://localhost:3000/auth/google/callback`)
4. 받은 클라이언트 ID와 보안 비밀을 `.env`의 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`에 넣고 서버를 다시 켜.

운영 서버에서는 `BASE_URL`을 `https://...` 주소로, `DEV_LOGIN=false`로 둬. HTTPS면 로그인 쿠키에 Secure가 붙어.

## 구조

```
src/
  index.js     설정 읽고 서버 시작
  server.js    Express API, 파일 업로드/다운로드, Socket.IO 실시간 이벤트
  auth.js      구글 OAuth 로그인, 개발용 로그인, 세션 쿠키
  service.js   대화·메시지·멤버·권한 규칙 (모든 검사가 여기 있어)
  db.js        SQLite 스키마
public/
  index.html, style.css, icon.svg
  app.js       화면 전체
  format.js    메시지 서식 해석 (테스트할 수 있게 DOM과 분리)
test/          서비스, API·소켓·구글 로그인, 서식 테스트
data/          DB(chat.db)와 첨부 파일 (git에 안 올라가)
```

## 보안 메모

- 바꾸는 요청에는 `X-Requested-With: chat` 헤더가 있어야 해서 다른 사이트에서 몰래 요청을 보낼 수 없어.
- 메시지는 항상 글자로만 그려서(HTML로 해석하지 않아) 스크립트가 끼어들 수 없어.
- 첨부 파일은 그 대화의 멤버만 받을 수 있고, 이미지·PDF 같은 안전한 형식만 브라우저에서 열려. 나머지는 내려받기로만 줘.
