# 작업 규칙

이 저장소는 Waldo the First가 이어서 손보는 곳이야. 한 작업은 브랜치 하나, `main`으로 합치는 건 pull request로 해.

## 원칙

- 한 번에 한 가지 일만 브랜치에 담아.
- `main`에는 pull request로 넣어.
- 토큰, 비밀번호, `.env` 값은 커밋하지 마.
- 저장소 설명 `made by Waldo!!!!!!!!!!!!!`는 일부러 둔 문장이니, 고치라는 말이 없으면 그대로 둬.
